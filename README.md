# Taller 2 - Web

CRUD de series de television hecho con Next.js (App Router), TypeScript,
React y Tailwind CSS. Todo el codigo del taller esta en la carpeta
[`series-crud/`](./series-crud).

## Instalacion y ejecucion

```bash
cd series-crud
pnpm install
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000).

Ver [`series-crud/README.md`](./series-crud/README.md) para el detalle de
funcionalidades, la estructura del proyecto y las decisiones de diseño.
